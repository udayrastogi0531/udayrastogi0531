<h1 align="center">🎬 It's Intro Time</h1>

### I'm a Computer Science student focused on building useful AI applications — from retrieval pipelines and LLM-powered tools to stateful agent workflows.

I like understanding how systems work end to end: how data enters an application, how it is processed, how an AI component makes use of it, and how the final experience becomes useful to a real person. My current learning and building direction is **Generative AI and Agentic AI**, supported by a foundation in **C++, DSA and full-stack development**.

### What I build

- **AI applications:** RAG-based document assistants, video understanding workflows, research assistants and career-focused AI tools.
- **Agentic workflows:** Tool calling, LangGraph state, sequential/parallel/conditional flows, persistence and multi-agent orchestration.
- **Applied problem solving:** Defensive URL and scam analysis, explainable outputs and evaluation-focused engineering.
- **Full-stack products:** React, TypeScript, Node.js, Express, FastAPI and database-backed applications.
- **Engineering foundations:** C++, data structures, algorithms, APIs, databases and practical software design.

### What I care about

Building beyond a prompt-and-response demo, keeping claims measurable, documenting limitations honestly, and turning what I learn into working software.
